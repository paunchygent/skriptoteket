# PR-0410: ST-21-11 Exam Converter Correction Replay Artifact-Set Consumer

## Problem

Sir Convert Story 58 hardens idempotent replay and correction replay artifacts.
Task 378 changes corrected Exam Converter PDF/QTI artifact authority from static
`correction_replay_*` named artifacts to immutable request-scoped artifact-set
references with `artifact_set_id` and `content_sha256`.

Skriptoteket's closed PR-0406/PR-0408 consumer still accepts the old compact
reference shape and downloads replay files through
`/v2/convert/jobs/{job_id}/artifacts/{artifact_key}`. That is no longer
sufficient for Story 58 final closeout: task-level approval in Sir Convert does
not prove the product consumer follows the new route contract.

## Goal

Update the authenticated Exam Converter consumer so corrected file actions use
the full Sir Convert correction replay artifact-set reference and fail closed
when that reference is absent or incomplete.

This PR is a bounded downstream companion for Sir Convert Story 58. It does not
reopen PR-0406/PR-0408 design decisions; it keeps the existing answer-key review
UI and only changes the artifact authority carried to download/save actions and
retained proof.

## Non-goals

- No Sir Convert producer, replay, idempotency, or storage changes.
- No local fallback to original job artifacts, static `correction_replay_*`
  aliases, browser state, or latest generated bytes.
- No broad Exam Converter layout/copy redesign.
- No public anonymous Exam Converter path changes.
- No transcript/audio/document-converter consumer changes in this PR.

## Implementation Plan

1. Regenerate or update the vendored Sir Convert OpenAPI declaration for the
   Task 378 route and replay-reference schema.
1. Extend the Exam Converter replay-reference parser to require the full
   `correction_replay_artifact_reference_v1` shape for corrected file action
   authority.
1. Carry `artifact_set_id` and `content_sha256` through the
   `ExamConverterReviewFileActionReference` projection.
1. Add a Sir Convert Gateway client method for the nested correction replay
   artifact route and route corrected file downloads/saves through it.
1. Keep first-pass/original-job artifact downloads on the existing named
   artifact route.
1. Update the retained correction-session Playwright proof so the redacted
   evidence records and asserts the nested correction replay route.
