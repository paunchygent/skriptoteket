### ST-32-08 Landing Authenticated-Value Copy Alternatives

### Source: Purpose

Retain the approved landing-page copy and hierarchy alternatives that informed
the `PR-0270` implementation.

The alternatives preserve the shipped `ST-32-07`/`ST-32-08` public-entry
baseline while testing how strongly the signed-in section should move beyond
Klassrumskartan and the code editor.

`PR-0270` selected Alternative B with a product-owner tweak to row I:
`Använd alla Skriptotekets appar och verktyg som finns tillgängliga.`

## Design Interpretation

### Source: Alternatives

- Alternative A keeps the current ledger rhythm and adds one broader
  signed-in value row.
- Alternative B leads with more apps and work tools, then treats saved work as
  the persistence guarantee. This is the selected direction.
- Alternative C splits account value into two compact columns: everyday teacher
  tools and contribution paths.

### Source: Shared Copy Changes

- `Skapa salen, placera eleverna, spara som PDF. Allt i webbläsaren.` becomes
  `Skapa salen, placera eleverna, spara som PDF eller för Excel. Som inloggad
  är alla dina klasser, grupperingar och klassrumsplaceringar sparade.`
- Numeric step markers use `I`, `II`, `III`.
- The signed-in section includes language close to:
  `Få tillgång till fler appar och arbetsverktyg samt ge förslag på nya appar
  som du anser skulle underlätta ditt arbete.`
