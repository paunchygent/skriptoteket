## Outcome And Purpose

A teacher in Härryda imports their Skola24 timetable into a Skriptoteket
working-time app without giving Skriptoteket any credentials or session. As a
first step, a one-time pull of every teacher, class and room timetable at
Hulebäcksgymnasiet feeds a mock scheduler that proves the data is complete
enough to rebuild the school's schedule.

## Decision Boundary

This ledger owns the client route, the handoff, the export scope and the
proof-of-concept data handling. The API facts live in the
[Skola24 API reference](ref-skript-general-skola24-timetable-api-for-the-signed-in-teacher-skola24-timetable-api-for-the-signed-in-teacher.md).
The working-time rules (Bilaga M, calculation periods) and the app's
architecture belong to the app's epic and ADRs, which do not exist yet.

## Closure State

D1–D12 are closed by the user's answers on 2026-10-20. A1 was closed by the
analysis of the proof-of-concept pull the same day. Building the mock scheduler, the
bookmarklet and the import endpoint each needs a backlog item; this ledger
does not authorize implementation.
