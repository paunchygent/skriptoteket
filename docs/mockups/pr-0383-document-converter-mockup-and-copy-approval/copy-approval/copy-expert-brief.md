# PR-0383 Document Converter Copy Expert Brief

## Assignment

This brief produced the approved Swedish v4 copy sheet for the Document
Converter mockup. The accepted handoff is recorded in `swedish-copy-v4.md`.

Use the included Repomix package as the source of truth. The package contains
the approved static HTML/CSS mockup, governing PR docs, product constraints, and
the visible-string inventory.

## Required Output

Return a concise Markdown proposal with:

1. A one-paragraph copy direction.
2. A table with one row per copy id from `visible-string-inventory.md`:
   - copy id
   - current placeholder
   - recommended Swedish string
   - optional alternative if useful
   - rationale
3. A separate section for accessibility labels for icon-only controls.
4. A short list of any copy questions that must be decided by the product
   owner before implementation.

## Product Contract

- The default workspace is HTML/CSS project preview.
- Batch conversion is secondary.
- The teacher supplies project inputs and chooses the desired output.
- The application owns renderer choices, asset safety, producer selection,
  preview storage, and low-level conversion logic.
- Paper size is a real user-facing output choice and is limited to A3/A4/A5.
- The visible output control exposes separate PDFs or combined PDF only.
- The backend may still support `both` internally, but `both` is not a visible
  user choice for `PR-0384`.
- Temporary previews can be rendered, refreshed, discarded, downloaded, or
  explicitly saved to `Mina filer`.

## Copy Guardrails

- Do not write final marketing copy or landing-page language.
- Do not add eyebrow or overline labels. Obvious surfaces must not be narrated
  with duplicate subheadings.
- Keep the interface dense, operational, and calm.
- Do not expose implementation terms such as artifact id, preview id,
  filesystem path, TTL, producer, renderer, route id, validation vocabulary,
  local/heavy lane, or backend internals.
- Do not add advanced-settings copy.
- Do not ask the user to make choices the application should infer or own.
- Preserve `Mina filer` as the existing product term unless you explicitly
  propose a product-wide naming question.
- Prefer short command labels over explanatory sentences.

## Out Of Scope

- Production Vue implementation.
- Backend/API contract changes.
- Template marketplace, template editing, uploaded fonts, or durable history.
- New controls or extra choices.
- Copy for PDF document content generated by the user's uploaded source.
