# Skriptoteket Mockups Index

Canonical mockup surface for layout-first UX direction that must be approved
before runtime implementation.

Bundle rules:

- Each mockup lives in its own bundle directory under `docs/mockups/`.
- The canonical entry doc for a bundle is `README.md`.
- Designer HTML/CSS submissions and winner iterations belong in bundle-local
  subfolders.
- Existing direct preview assets such as `index.html`, `designer-a.html`, or
  SVG files remain valid bundle resources and may be linked from backlog docs.
- Non-Markdown resources are intentionally permissive in this lane. Designers
  may use HTML, CSS, JS, SVG, raster images, font files, JSON fixtures, and
  other bundle-local assets needed for layout/component experiments.
- Docs validation governs Markdown bundle records. It should not over-regulate
  creative proofing assets or turn `docs/mockups/` into a production asset
  pipeline.
