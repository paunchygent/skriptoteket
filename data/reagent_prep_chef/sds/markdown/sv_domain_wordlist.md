# Svensk domänordlista för SDS-översättningar

Den här ordlistan används för att hålla terminologi konsekvent och säker vid översättning av
säkerhetsdatablad (SDS) till svenska.

Målet är att undvika "nästan-rätt" maskinöversättningar i kritiska uttryck (faro-/skyddsangivelser,
första hjälpen, PPE och SDS-sektionsrubriker).

## Icke-CLP (förekommer i vissa SDS)

Vissa leverantörer använder P-koder som inte finns i äldre listor (t.ex. P316/P317). När de
förekommer i käll-SDS översätts de bokstavligt och konsekvent:

| Kod | Engelska i källan | Svensk översättning |
| - | - | - |
| P316 | Get emergency medical help immediately. | Sök omedelbart akut läkarhjälp. |
| P317 | Get medical help. | Sök läkarhjälp. |
